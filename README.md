# 🧁 Bakely

**Bakely — A recipe-focused web application**

Bakely is my final degree project, developed as part of my Frontend Developer education at Medieinstitutet. The project gave me the opportunity to apply my frontend development skills and bring together design, user experience and web development in a single application.

The goal was to create a visually appealing and user-friendly experience centered around recipes and baking.

## 🌐 Live Demo

[**Explore Bakely here →**](https://bakely-pi.vercel.app/)

## ✨ Features

- Recipe-focused interface with a clean and welcoming design.
- Responsive layout designed to provide a good user experience across different screen sizes.
- Component-based architecture built with React.
- Styled interface using SCSS and Bootstrap.

## 🛠️ Tech Stack

- **React** — Building reusable UI components.
- **TypeScript** — Adding type safety and improving code maintainability.
- **Vite** — Development server and build tooling.
- **SCSS** — Styling and organizing CSS.
- **Bootstrap & React Bootstrap** — Layout and UI components.
- **Lucide React** — Icons.
- **Supabase JS** — Database and backend integration tools.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/annappersson/Bakely.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Bakely
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Starts the development server. |
| `npm run build` | Builds the application for production. |
| `npm run preview` | Previews the production build. |
| `npm run lint` | Runs ESLint to check code quality. |
